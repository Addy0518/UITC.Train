# 綜合專案心得

1. git checkout 分支名稱 => 切換到這個分支

2. git checkout -b 分支名稱 => 複製一個現在所在的分支

3. git diff => 查看這個分支目前做了什麼修改

4. git add 資料夾名稱 ( 例如 : Controllers ) => 把這個資料夾內的檔案都加到暫存區 , 準備 commit

5. git commit -m "要 commit 的訊息" => commit 上去

6. git push origin 分支名稱 => 推到遠端

7. git pull origin 分支名稱 => 把這隻分支的遠端給拉下來同步

8. git rebase 分支名稱 => 把這隻分支跟現在的分支合併
